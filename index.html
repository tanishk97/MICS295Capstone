SalsaG CLI Plugin Integration

This website demonstrates the new SalsaG CLI plugin approach:

  • Portable CLI Tool - Works anywhere with salsaG start --artifact ./dist
  • Single Command - Replaces entire embedded pipeline
  • Configurable - YAML-based configuration
  • CodeBuild Integration - Uses IAM roles automatically
  • Central Trust Ledger - DynamoDB single source of truth

Pipeline Comparison

❌ Old Approach (Embedded)

- SBOM generation step
- SLSA provenance step  
- Cosign signing step
- S3 upload step
- DynamoDB logging step

salsaG start --artifact ./dist
